this program was written by AI for use with Tait Radios (https://www.taitcommunications.com) to receive location data and track on a map for safety purposes.

It is intended as a lightweight solution for small teams.  I've developed this for use for a youth development related organisation with 20-30 radios.

Features:
-web server interface
-receives data from any Tait Radio that supported CCID connected via serial port
-it can either connect to a radio configured as a "data dispatcher" or can poll radios directly
-works for radios that are either configured for P25 or DMR
-OpenMaps for online map use 
-geocoded PDF's such as government issued topographic maps for entirely offline operation
-will display radio location co-ords in either Lat/Long or MGRS
-supports locally configured radio aliases and custom colours
-logs all position data for replay or non-real-time analysis
